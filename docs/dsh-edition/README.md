# Coucou DSH Edition

Личная сборка Coucou for Windows, в которой DeepSeek Harness (DSH) — полноценный агент
острова: состояние, активность, разрешения, модель и усилие рассуждения.

**Это не публичный продукт.** Репозиторий приватный, канал обновлений приватный,
распространение не планируется. Имя «Coucou», персонаж Mochi, иконка и звуки остаются
собственностью Louis Raillé и **не** покрыты MIT — см. [`LICENSE-ASSETS.md`](../../LICENSE-ASSETS.md)
в корне. Для любого публичного распространения потребуется отдельное имя, иконка, персонаж
и звуки.

## База

| Что | Значение |
|---|---|
| Upstream | [`Louis-CFM/coucou`](https://github.com/Louis-CFM/coucou) |
| Базовая ветка | `dsh/0.5.9` от тега `windows-v0.5.9` (`7436363`) |
| Установленная версия | Coucou 0.5.9 (MSI `{8213F4CF-8440-4442-A869-6D6D0B873D2B}`) |
| Версия DSH | 0.2.2-rc.1 |

Тег `windows-v0.5.9` выбран потому, что он совпадает с установленным приложением и прошёл
релизную проверку. `upstream/main` содержит незарелизенную разработку 0.6 (114 коммитов
впереди, раздел `0.6.0 — Unreleased` в `CHANGELOG.md`); синхронизация с ней — отдельный
этап после того, как интеграция заработает.

## Правила работы

- Никакого автоматического разрешения операций DSH; отсутствие ответа — не разрешение.
- Не обходить штатный `approval/request`; не менять политику разрешений.
- Не менять глобальные настройки DSH при переключении модели/усилия сессии.
- Не записывать секреты, токены, полные команды и содержимое сообщений в логи.
- Тестовые сборки не устанавливать поверх рабочего приложения.
- Старый мост `CoucouDshBridge` сохраняется до подтверждения новой интеграции.
