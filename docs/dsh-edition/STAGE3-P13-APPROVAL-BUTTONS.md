# Почему не было кнопок разрешения

**Дата:** 2026-11-14  
**Точка отката:** `520cc6eaa55e165e6ea4f3e6bff19f5ee1d1a09d`

## Причина: моя ошибка в настройках, а не в карточке

`cordis.patch.yml` изменён в **00:22:55**, и в журнале приложения:

```
00:22:55 dsh plugin: profile backed up to ...\backups\cordis.patch.yml.1794604975.bak
00:22:55 dsh plugin: removed from the profile
```

Это мой собственный установщик — то есть в настройках нажали «удалить». После
этого мост снят, плагин не перехватывает запросы, и карточка честно показывает
запасной вариант: «ответьте в терминале». Отсюда и «просит ткнуть самому».

**Почему нажали:** в моей секции настроек кнопки были **без подписей**.

```ts
const install = h("button", { class: "btn primary", onclick: () => act(true) });
const remove  = h("button", { class: "btn",         onclick: () => act(false) });
```

Два пустых прямоугольника рядом, правый выключает мост, подтверждения нет.
Плюс класс `btn` в `settings.css` не существует — кнопки были ещё и без стиля.

## Что исправлено

| Было | Стало |
|---|---|
| пустые кнопки | «Установить мост» / «Убрать мост» |
| класс `btn` (нет такого) | `primary` / `danger`, как на всей странице |
| удаление в один клик | второй клик подтверждает: «Подтверждения перестанут работать. Всё равно убрать?» |
| в подписи — путь к папке | «Без него DSH спрашивает разрешения в своём окне.» |

4 новые строки в 14 языках.
