## 5. Что ещё не проверено

1. **Сквозное разрешение с реальным агентом.** Сейчас в сессии стоит политика `never`,
   при которой DSH отклоняет запросы **до** answerer'ов — плагин их вообще не видит.
   Для проверки нужно переключить политику на `ask` и вызвать инструмент, требующий
   подтверждения. Это изменение вашей рабочей сессии — нужно ваше решение.
2. **Переключение модели/усилия из острова.** Код есть (`session.setConfig`), но
   проверено только чтение. Проверка требует команды извне и активного хода.
3. **DACL канала.** Сейчас защита — токен и приватный каталог. Ограничение по SID на
   уровне Windows ACL не сделано.
4. **Проверка версии DSH при старте.** Константа есть, автопроверки нет.

## 6. Важное замечание про политику разрешений

В момент проверки в сессии действует `never` («never ask the user for approval»).
Это значит, что **сейчас** карточки разрешений в острове не появятся в принципе: DSH
отклоняет такие операции до того, как плагин получит запрос. Для демонстрации нужно
вернуть политику `ask`.
